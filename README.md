## 🎯 学习路线

### 零基础部分 (Day 01 - Day 18)
1. **环境搭建** - JDK安装与配置
2. **基础语法** - 变量、数据类型、运算符
3. **控制结构** - 分支、循环语句
4. **方法** - 方法定义与递归
5. **面向对象基础** - 类、对象、封装
6. **关键字** - this、static、super

### 进阶部分 (Day 19 - Day 35)
1. **面向对象进阶** - 继承、多态、抽象类、接口
2. **数组** - 一维数组、二维数组
3. **常用类** - String、包装类、日期时间
4. **异常处理** - try-catch、自定义异常
5. **集合框架** - List、Set、Map
6. **IO流** - 文件操作、字节流、字符流
7. **多线程** - 线程创建、同步、线程池
8. **反射机制** - Class类、动态代理
9. **注解** - 内置注解、自定义注解

## 💡 学习建议

1. **按顺序学习** - 严格按照Day01到Day35的顺序学习
2. **动手实践** - 每天的源码都要亲自敲一遍
3. **完成作业** - 认真完成每章的课后作业
4. **思维导图** - 利用思维导图梳理知识点
5. **复习笔记** - 经常回顾每日的课堂笔记

## 📝 文件编码说明

本项目中的文本文件和Java源文件使用 **GBK** 编码，如果出现乱码：

### VS Code / Cursor 解决方法：
1. 点击右下角的编码显示
2. 选择 "Reopen with Encoding"
3. 选择 "GBK" 或 "Simplified Chinese (GB18030)"

或在设置中启用自动编码检测：
```json
{
    "files.autoGuessEncoding": true
}
```
